# Security policy

## Supported versions

Security fixes apply to the **latest** **[kwd-selfhosted](https://github.com/hrodrig/kwd-selfhosted)** **`main`** / tagged release of deployment manifests, in combination with supported **[kwd](https://github.com/hrodrig/kwd)** application releases.

## Reporting a vulnerability

Please report security vulnerabilities for the **kwd** project (including deployment docs in this repo) via **[GitHub private vulnerability reporting](https://github.com/hrodrig/kwd-selfhosted/security/advisories/new)** on **kwd-selfhosted**, or the equivalent on **kwd** if the issue is application-only — whichever matches the code you are reporting against.

Do not open public issues for undisclosed security vulnerabilities.
